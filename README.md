# Tinitiate training

Open [index.html](index.html) to browse the nine fictional companies. Each company lives in `domains/<company>/`
with a home page, an Assignments tab, a Control Tower tab and an `sql` subfolder with its data and assignments.
See [domains/README.md](domains/README.md) for the layout.

For SQL, start with the [domain assignments and hard interview practice](domains/SQL/Excerises/DOMAIN_ASSIGNMENTS.md). Student assignments are in each company's `sql/questions` folder, with matching private instructor files in its `sql/solutions` folder.

Every SQL domain has all 132 subtopics, with 15 Beginner, 15 Intermediate and 15 Advanced questions per subtopic: 5,940 levelled questions per domain. Practice and interview handouts use identical canonical IDs and prompts.

The [earlier cross-subject draft](interview-practice-bank/catalog.md) remains available for other training subjects. Its SQL section is superseded by the domain assignments above.

Rebuild the HTML pages with `python build_site.py`.
