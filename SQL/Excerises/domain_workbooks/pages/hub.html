How it works

Every workbook follows the same path, so switching industries never means relearning the layout.

  • Run one setup scriptEach domain folder has a data_setup.sql. Run it once in a new practice database.
  • Same 16 topicsFrom DQL, joins and aggregates to DDL, constraints, CTEs and window functions.
  • Three levels per topicAdvanced questions are interview patterns: top-N per group, running totals, gaps and islands, fan-out traps.
  • Then the Interview Challenges10 multi-step problems per company, like real interview rounds. The approach hint opens with the expected result, so try first.
  • Check your own resultRun your SQL first, then compare rows. A different query that returns the same rows is still correct.
