How it works

Every workbook follows the same path, so you can switch industries without relearning the layout.

Same 16 topics

Introduction, DQL, operators, aggregates, joins, set operations, data types, DDL, constraints, DML, security, string and date functions, subqueries, CTEs and window functions.

10 / 10 / 10 per topic

Beginner, Intermediate and Advanced questions. Advanced ones are interview patterns: top-N per group, running totals, gaps and islands, fan-out traps.

Check your own result

Write and run your SQL first, then compare with the expected rows. A different query that returns the same rows is still correct.

One setup script

Each domain folder has a data_setup.sql. Run it once in a new practice database and every question works.
